# 5201Final
Final project for course 5201 Microservices and cloud computing at MSOE

This application code is not configured to run on a cloud computing platform. This configuration will work locally.

In order to run the application, start the validation and high consumers

Run the producer to get a base of bids randomly generated from the script

Stop the producer after a few bids have been placed

Run the streamlit application to see the auction dashboard and palce bids of your own

Use the "Place Bid" button to open a dialog screen that takes input

Submit the form to send a message that will be validated and published if your bid is high enough!

There is a link to auction dashboards to view for data visualization per auction item

There is also a kafka dashboard to track the usage and performance metrics of the kafka consumers
